# PDFLite 应用图标

白色连续圆角底板上几行深墨蓝文字，中间一行被青柠色荧光笔划过，荧光带两端斜切、左右伸出文字行。表达「读论文、划重点」，不再画纸张和折角。

## 文件

- `render.swift`：唯一源文件。用 CoreGraphics 按参数绘制，无第三方依赖；颜色、行位置、荧光带都在顶部 `Palette` / `Detail` 中。
- `source.png`：1024 × 1024 渲染结果，仅供查看。
- `preview.png`：浅色 / 深色背景下 128、64、32、16pt（Retina）的对照图。
- `../../PDFLite/Resources/AppIcon.icns`：应用实际使用的多尺寸图标。
- `../../browser-extension/icons/icon{16,32,48,128}.png`：浏览器扩展图标（同一设计，底板更满、无投影）。

运行 `./design/AppIcon/build.sh` 重新生成以上全部产物。

## 设计参数

| 项 | 值 |
| --- | --- |
| 底板 | macOS 网格 824/1024；直边 + 四分之一超椭圆拐角（半径 22.5%）；`#FFFFFF` → `#EEF0F3` 竖向渐变，7% 黑内描边，下方柔和投影 |
| 文字行 | `#3A4560`；被划过的一行 `#1D2B4B` |
| 荧光笔 | `#C8F03C`，平行四边形，斜切量 3 单位 |

尺寸分层（按底板实际像素）：

- ≥ 50px：五行文字，第三行被划过。
- 22–49px（32、48px）：三行加粗，像素对齐。
- < 22px（16px）：三道 1px 级横线，荧光带不斜切，像素对齐。
